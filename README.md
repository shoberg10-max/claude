# 漢字検定8級 もんだいれんしゅう

漢字検定8級（小学3年生修了程度）の練習ができる、ブラウザだけで動くWebアプリです。
ビルド不要・依存ライブラリなしの素のHTML/CSS/JavaScriptで作られています。

## 遊び方

1. `index.html` をブラウザで開く（もしくは下記のローカルサーバーで配信する）
2. もんだいの しゅるい（読み方・書き取り・画数・漢字えらび・ことばのペア・まとめて）と もんだい数 を選ぶ
3. 「はじめる」を押して回答していく
4. 結果画面でスコアとまちがえた問題を確認し、「まちがえた問題だけやり直す」で復習できる
5. 成績とにがてな問題はブラウザの localStorage に保存され、ホーム画面にいつでも表示される

## もんだいの しゅるい

- **読み方**: 漢字（熟語・訓読み語）を見てひらがなで読みを答える
- **書き取り**: ひらがなを見て漢字（送りがな含む）で書く
- **画数**: 漢字を見て総画数を4択で答える
- **漢字えらび**: 形が似ている2つの漢字（例: 丸い／九い）から、ひらがなに対応する正しいほうを選ぶ
- **ことばのペア**: 「夜⇔朝」「重い⇔軽い」のように対になることばを漢字で書く
- **まとめて**: 上記5種類をランダムに出題

出題は 小学3年生で新しく習う漢字（8級の対象漢字、約200字）から、それぞれの代表的な熟語・訓読みの言葉を使って生成しています。実際の検定の過去問そのものではなく、同じレベル感で作成したオリジナルの練習問題です。

## ローカルでの実行

ビルド不要です。ファイルをそのまま開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## ファイル構成

- `index.html` — 画面構造（ホーム／クイズ／結果の3画面）
- `style.css` — スタイル
- `data.js` — 出題データ（`KANJI_DATA` / `CHOICE_DATA` / `PAIR_DATA`）
- `app.js` — 出題ロジック・採点・成績保存（localStorage）

## データを増やす

`data.js` の各配列に以下の形式でオブジェクトを追加すると、自動的に出題されます。

読み方・書き取り・画数の3種類は `KANJI_DATA` に追加:
```js
{ kanji: "医", word: "医者", reading: "いしゃ", strokes: 7 }
```

漢字えらび（二択）は `CHOICE_DATA` に追加:
```js
{ reading: "ようじん", correct: "用心", wrong: "用思" }
```

ことばのペアは `PAIR_DATA` に追加（a・bどちらの向きからも出題される）:
```js
{ a: { kanji: "夜", reading: "よる" }, b: { kanji: "朝", reading: "あさ" } }
```
