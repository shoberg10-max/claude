# 資料作成支援アプリ

会議メモ・議事録から次回会議に向けた資料の構成案を作成し、あらかじめ用意したコンサルスライドのデザインパターンから内容に合うものを自動選択して、PowerPoint（.pptx）として書き出すブラウザアプリです。

官公庁向け報告書・提案書（BCG・マッキンゼー・デロイト・NRI・アビーム等のコンサルティングファームが作成するようなレベル感）を想定し、スライドはテキストヘビーを基本としています。すべてのスライドは共通して「①タイトル（トピックラベル）→②メッセージ（リード文＋サブメッセージで結論を先に示す）→③ボディ（メッセージの根拠となる図・表・チャート）」という3層構成（ピラミッド原則）で統一されます。配色は青を基調としたモノトーンです。

ビルド不要の素の HTML / CSS / JavaScript で作られているので、`index.html` を開くだけで動きます（PowerPoint出力ライブラリの [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) はCDNではなく `js/vendor/` にローカル同梱しているため、社内の隔離ネットワーク環境でもそのまま動作します）。

## つかいかた

```
python3 -m http.server 8000
```

を実行して、ブラウザで `http://localhost:8000` を開いてください（`index.html` を直接ダブルクリックしても動作します）。

1. **Step 1（会議メモを入力）**: 会議メモ・議事録を貼り付けます。`#`/`##` の見出しや `-`/`・` の箇条書きがあると精度が上がりますが、フリーテキストでも解析します。「サンプルを試す」で動作イメージを確認できます。
   - **構成案がうまくはまらないとき**は「🪄 社内LLM用プロンプトを作成」を押してください。このアプリの読み取りフォーマットに合わせて会議メモを整形するためのプロンプトが生成されます。それを社内LLMのチャットに貼り付けて実行し、出力された構成案をコピーして入力欄に貼り付け直してから「次へ」を押すと、高い精度で構成案（リード文・サブメッセージ込み）に変換されます。
2. **Step 2（構成案を確認・編集）**: メモから自動生成したスライド構成（見出し・リード文・サブメッセージ・箇条書き）を確認し、自由に編集・追加・削除・並べ替えできます。リード文（メッセージ）はそのスライドの結論を一文で表すもので、空欄のままだと先頭の箇条書きが自動的に使われます。
3. **Step 3（デザインパターンを自動選択 → PowerPoint書き出し）**: 各スライドの内容（項目数・キーワード・数値の有無など）から最もふさわしいデザインパターンをルールベースで自動選択してプレビューします。Step 1のプロンプトを使った場合は、社内LLMが構成案の中で提案したパターン（🤖 AI選択）がそのまま使われます。プレビュー右上のプルダウンからいつでも手動で変更できます。「PowerPointを書き出す」でPCに `.pptx` ファイルがダウンロードされます。

## スライドの構成（3層構造）

すべてのパターンで共通して、次の3層構造を使います（`js/pptxExport.js` が共通描画し、パターンごとの実装は③のみを担当します）。

1. **タイトル**（トピックラベル）: ページ上部の細い見出し。「現状の課題」のような短い体言止め
2. **メッセージ**（リード文＋サブメッセージ）: 淡い青の帯の中に、そのスライドの結論・示唆を一文で言い切るリード文（太字）と、任意で補足のサブメッセージを表示。結論を先に示す「ピラミッド原則」に沿った構成
3. **ボディ**: メッセージの根拠を示す図・表・チャート（枠線付き）。ここが各デザインパターン固有のレイアウト

Step 1のプロンプトが生成する `> リード文` / `>> サブメッセージ` の記法（`js/outline.js` が解析）を使うと、社内LLMに考えさせたメッセージをそのままこの構成に流し込めます。Step 2でも各スライドカードにリード文・サブメッセージの入力欄があるので、手動での追記・修正も可能です。

## 用意されているデザインパターン（23種類・8カテゴリ）

`js/patterns.js` で定義しています。同じカテゴリに複数のパターンが登録されている場合、Step 3のプルダウンでは同じカテゴリ内にグループ表示され、「同じ用途の別デザイン」として選び直せます（例：フローだけで3種類、比較だけで3種類）。自動選択は各カテゴリの中から内容に最も合うものを選びますが、迷ったときのための代替候補として他のパターンも常に選択可能です。

| カテゴリ | パターン | 使いどころ |
|---|---|---|
| 汎用 | タイトル＋メッセージ | キーメッセージ＋補足の箇条書き。汎用のフォールバック |
| 汎用 | アジェンダ／目次 | 本日お伝えする項目を番号付きリストで示す（表紙・目次向け） |
| 比較 | ボックス比較 | 2〜4個の選択肢・案を横並びで比較 |
| 比較 | 縦型比較 | 項目数が多い・説明が長い場合の縦並び比較 |
| 比較 | 比較表 | 5項目以上を表形式で一覧比較 |
| マトリクス／ポジショニング | 2軸マトリクス | 4象限で分類・整理する |
| マトリクス／ポジショニング | SWOT分析 | 強み・弱み・機会・脅威の4象限で整理する |
| マトリクス／ポジショニング | ポジショニングマップ | 2軸の座標平面上に複数項目をプロットする |
| フロー・プロセス | プロセス／フロー | 手順・ステップを横並びで順番に示す |
| フロー・プロセス | 縦型プロセスフロー | ステップ数が多い場合の縦並びフロー |
| フロー・プロセス | サイクル図 | PDCAなど繰り返すプロセスを円環で示す |
| 構造・ロジック | ピラミッド構造 | 結論を頂点に、根拠（課題・原因・対策など）を土台に示す |
| 構造・ロジック | 階層ピラミッド | ビジョン→戦略→施策など2〜3段階の階層を三角形の積み上げで示す |
| 構造・ロジック | ロジックツリー | テーマを複数の要素に分解して示す（MECE整理） |
| 変化・対比 | Before／After | 現状と施策後を対比させる |
| 変化・対比 | ファネル図 | 歩留まり・コンバージョンなど段階的に絞り込まれるデータを示す |
| 変化・対比 | ウォーターフォール | 数値の増減要因を積み上げ棒で示す（開始値→各要因→終了値） |
| 時系列 | タイムライン／ロードマップ | 日付・フェーズを横並びで時系列に示す |
| 時系列 | 縦型タイムライン | マイルストーンが多い場合の縦型タイムライン |
| 数値・グラフ | KPIサマリー | 数値・指標をカードで並べる |
| 数値・グラフ | 棒グラフ | 複数項目の数値を比較する（PowerPointのネイティブグラフ） |
| 数値・グラフ | 折れ線グラフ | 数値の時系列推移を示す（PowerPointのネイティブグラフ） |
| 数値・グラフ | 円グラフ／構成比 | 構成比・内訳をドーナツ／円グラフで示す（PowerPointのネイティブグラフ） |

棒グラフ・折れ線グラフ・円グラフはPptxGenJSの`addChart`機能を使ったPowerPoint本来のネイティブグラフとして生成されるため、書き出し後もPowerPoint上で数値やデザインを直接編集できます。

## デザインパターンを増やす（拡張方法）

パターンの追加・変更は `js/patterns.js` の1ファイルで完結します。以下の形のオブジェクトを `DocAssist.patterns` 配列に追加するだけで、自動選択・手動切り替えプルダウン・プレビュー・PowerPoint書き出しのすべてに反映されます。

```js
{
  id: 'kebab-case-id',        // 一意なID
  name: '表示名',
  category: '比較',           // 既存カテゴリ名と揃えると、プルダウンで同じ用途の兄弟候補としてまとまる
  description: '説明文（パターン一覧やプレビューに表示）',
  score(section) { ... },     // {heading, bullets} を見て 0〜10 程度で採点する関数
  renderBody(bullets) { ... },              // プレビュー用HTML文字列を返す（見出しは共通枠が描画）
  buildBody(pptxSlide, bullets, theme, box) { ... }, // PptxGenJSでスライド本文を組み立てる
}
```

`js/analyze.js` にキーワード検出・数値検出・箇条書きのキー：バリュー分解などの共通ヘルパーがあるので、新しいパターンの `score()` 実装に利用できます。色は `js/theme.js` の1箇所で管理しているので、配色を変えたい場合もそこを直すだけです。同じ用途で見た目違いのバリエーションを増やしたい場合は、既存パターンと同じ `category` を指定するだけでプルダウンにまとまります（例：`フロー・プロセス`, `比較`, `マトリクス／ポジショニング`, `構造・ロジック`, `変化・対比`, `時系列`, `数値・グラフ`, `汎用`）。

## 社内LLM環境との連携（コピー＆ペースト方式）

社内の隔離LLM環境はAPIから直接呼び出せないことが多いため、このアプリは**プロンプトをコピーして社内LLMのチャットに貼り付ける**方式で連携します。

Step 1の「🪄 社内LLM用プロンプトを作成」（`js/promptBuilder.js` の `DocAssist.buildOutlineFormatPrompt(rawNotes)`）を押すと、次の内容を含むプロンプトが生成されます。

- 入力した会議メモ本文
- 官公庁向け報告書・提案書レベルの情報量・テキストヘビーな記述を求める指示
- このアプリのパーサー（`js/outline.js`）が確実に読み取れる出力フォーマットの指定（`# タイトル` → `## 見出し` → `> リード文` → `>> サブメッセージ`（任意） → `- 箇条書き` の構造、比較項目は「項目名：説明」で書くこと、など）
- 利用可能なデザインパターン一覧（id・名前・説明）と、見出しの直後に `[pattern: パターンID]` の形式で最もふさわしいパターンを提案させる指示

このプロンプトを社内LLMで実行して得られた出力をStep 1の入力欄に貼り付け直すと、

1. きれいに構造化された構成案として読み込まれる（Step 2でも編集可能）
2. 見出しに含まれる `[pattern: xxx]` タグを `js/outline.js` が自動検出し、Step 3でそのパターンが「🤖 AI選択」として最初から適用される

という2つの効果が一度に得られます。タグが付いていない、または未知のIDの場合は自動的に無視され、通常どおりルールベースの自動選択（`js/patternSelector.js`）にフォールバックします。

社内LLMのプロンプト仕様に合わせて文言を調整したい場合は `js/promptBuilder.js` の1ファイルを直せば反映されます。パターン一覧は `DocAssist.patterns` から自動生成しているので、パターンを追加してもプロンプトの更新は不要です。

## ファイル構成

```
index.html
css/style.css          全体のスタイル（プレビューのスライドデザインも含む）
js/app.js               画面遷移とUI（3ステップウィザード）
js/outline.js           会議メモ → 構成案（見出し＋箇条書き）のパーサー
js/analyze.js           キーワード検出・数値検出などの共通テキスト解析ヘルパー
js/patterns.js          デザインパターン定義（採点・プレビュー・PPTX生成）※拡張ポイント
js/patternSelector.js   構成案の各スライドに最適なパターンを選ぶロジック（ルールベース）
js/promptBuilder.js     社内LLMにコピペするための構成案整形プロンプトを組み立てる
js/pptxExport.js        構成案 → PowerPoint(.pptx) ファイルの書き出し
js/theme.js             プレビュー／PPTX共通の配色定義
js/vendor/pptxgen.bundle.js  PowerPoint生成ライブラリ PptxGenJS（MITライセンス、ローカル同梱）
```

## 制限事項

- 構成案生成はルールベースのため、フリーテキストのままだと見出し・箇条書きの区切りが意図通りにならないことがあります。うまくいかない場合は「🪄 社内LLM用プロンプトを作成」を使うか、Step 2で自由に修正してください。
- アプリ自体はAPI通信を一切行わないため、会議メモの内容が外部に自動送信されることはありません。社内LLMへの連携は、ユーザーが手動でプロンプトをコピー＆ペーストする操作を介してのみ行われます。
