# ゆるもじ島の漢字たんけん隊

ゆるキャラと一緒に冒険しながら、漢検9級・8級レベルの漢字を楽しく学べるブラウザアプリです。ビルド不要の素の HTML / CSS / JavaScript で作られているので、`index.html` を開くだけで動きます。

## あそびかた

```
python3 -m http.server 8000
```

を実行して、ブラウザで `http://localhost:8000` を開いてください（`index.html` を直接ダブルクリックしても動作します）。

## iPhone / iPad で動かす（サーバーなし・1ファイル版）

このアプリは `index.html` が `css/style.css` や `js/*.js` を個別に読み込む構成なので、
そのままzipで送って展開しても、iOSのSafariでは「他のファイルを読み込めない」ために
真っ白になることがあります。そこで、全部を1つの `.html` に埋め込んだ単体ファイルを
作れるようにしてあります。

```bash
node build/bundle.js
```

`dist/index.html` が生成されます。これは外部ファイルへの参照が一切ない、この1つの
htmlファイルだけで完結する版です。あとは、

1. `dist/index.html` を（必要ならzipにして）iPhone/iPadに送る（AirDrop・メール・メッセージなど）
2. zipの場合はFilesアプリでタップすると自動的に展開される
3. 展開された `.html` をタップ → 共有シートから「Safariで開く」

でそのまま動きます。オフラインでも動作し、進み具合は各端末のSafariのlocalStorageに
保存されます（他の端末とは共有されません）。ホーム画面に追加すればアイコンからも開けます。

`dist/` はビルド成果物なのでgit管理していません（`js/`・`css/`の元ファイルを編集したら
`node build/bundle.js` を再実行してください）。

## ゆるもじ島（メイン機能）

漢検10級（1年生配当80字）・9級（2年生配当160字）・8級（3年生配当199字）の漢字を、育成ゲーム風のループで学習します。

- **しまマップ**：覚えた漢字の数に応じて島の霧が晴れていく
- **ミッション**：読み・かんじさがしを混ぜた8問＋書き取り練習（なぞり書き）で1セット
- **ふくしゅうミッション**：一度おぼえた漢字をしばらく出題していないと「わすれんぼう」が出現。忘れかけの字だけを復習して撃退する
- **ごほうび**：ミッションクリアでコイン・けいけんちを獲得。もじまるがレベルアップし、なかまキャラも仲間になる
- **進化**：もじまるは Lv.10 / 20 / 30 で頭の芽が育ち、見た目が4段階に変化する
- **敵キャラ**：漢字をまちがえると「まちがえ鬼」が出現。失敗ではなく倒す対象として見せる
- **たからばこ**：ミッションでもらえるチケットを使って、かぶりものアイテムをコレクション
- **かんじ図鑑**：レベルごとの全漢字を一覧表示（例となることば・読み方付き、おぼえた漢字はゴールド表示）
- **漢検チャレンジ**：20問のもぎテストで実力チェック。正答率に応じて合格圏／もう少し／要特訓を判定
- **おうちの方へ**：簡単な計算チェックの先に、週間学習記録・苦手な漢字・もぎテスト推定合格度を表示

進み具合はすべてブラウザの localStorage に保存されます（サーバーへの送信なし）。

## ３年生 さんすう・かんじ ドリル（従来機能）

ゆるもじ島のホーム画面から「さんすう・3年生のドリルはこちら」で引き続き利用できます。

### さんすう（6種類・各10問）

- たし算・ひき算（2〜4けた）
- かけ算（九九〜3けた×1けた）
- わり算（あまりなし）
- あまりのあるわり算
- 大きい数のくらべっこ（＜・＞・＝）
- 大きい数の位（一の位〜十万の位）

### かんじ

小学3年生で習う漢字200字すべてを収録。よみかたクイズ・かんじさがしクイズ・かんじ一覧。

## アートについて

キャラクター・アイテム・UIアイコンはすべて、文字グリッドで定義したドット絵を
SVGの矩形に変換して描画しています（画像ファイルなし）。

- キャラは 20x18、UIアイコンは 12x12
- 全キャラが共通の体の骨格を使うので、表情1セットが全員に載る
- キャラごとの色はパレット上書きで指定（1キャラ＝主役の色1つ＋共通の輪郭色）
- `Sprites.setStyle('vector')` で、初期に作ったベクター版に切り替え可能

## データについて

9級・8級の出題データ（漢字・ことば・読み方・画数）は、同リポジトリの
`claude/kanji-kentei-8-app-d3s15h` ブランチで作成した漢検8級・9級練習アプリの `data.js`
（`GRADE2_DATA`＝9級、`KANJI_DATA`＝8級）と同じ内容を使っています。10級（1年生配当80字）は
[davidluzgouveia/kanji-data](https://github.com/davidluzgouveia/kanji-data)（KANJIDIC由来）
から該当する80字を抽出し、同じ形式（ことば・読み方）でこのアプリ用に作成しました。

漢検の級と学年の対応は 10級＝小学1年生修了程度、9級＝小学2年生修了程度、8級＝小学3年生修了程度です
（7級＝4年生、…と続く）。

