# 漢字検定8級・9級 もんだいれんしゅう

漢字検定8級（小学3年生修了程度）・9級（小学2年生修了程度）の練習ができる、ブラウザだけで動くWebアプリです。
ビルド不要・依存ライブラリなしの素のHTML/CSS/JavaScriptで作られています。

## 遊び方

1. `index.html` をブラウザで開く（もしくは下記のローカルサーバーで配信する）
2. きゅう（9級／8級）と もんだいの しゅるい（読み方・書き取り・画数・漢字えらび・ことばのペア・部首なかま・筆順・まとめて）、もんだい数 を選ぶ
3. 「はじめる」を押して回答していく
4. 結果画面でスコアとまちがえた問題を確認し、「まちがえた問題だけやり直す」で復習できる
5. 成績とにがてな問題はブラウザの localStorage に保存され、ホーム画面にいつでも表示される

## もんだいの しゅるい

- **読み方**: 漢字（熟語・訓読み語）を見てひらがなで読みを答える
- **書き取り**: ひらがなを見て漢字（送りがな含む）で書く
- **画数**: 漢字を見て総画数を4択で答える
- **漢字えらび**: 形が似ている2つの漢字（例: 丸い／九い）から、ひらがなに対応する正しいほうを選ぶ
- **ことばのペア**: 「夜⇔朝」「重い⇔軽い」のように対になることばを漢字で書く
- **部首なかま**: 同じ部首（さんずい・きへん・ごんべん など）を持つ漢字のなかまを選ぶ。9級・8級共通の出題
- **筆順**: 漢字の中で太く強調された画が、正しい書き順で何画目にあたるかを4択で答える
- **まとめて**: 上記7種類をランダムに出題

出題する漢字は、文部科学省「学年別漢字配当表」の第2学年（9級・160字）・第3学年（8級・200字）配当漢字にもとづいています（複数のWeb検索で他の教育情報サイトの一覧と突き合わせて確認済み）。ただし実際の検定は各級までに習った漢字すべてが累積して出題範囲になる（例: 8級は440字）のに対し、このアプリは各級で新しく習う漢字だけを対象にしています。また問題文自体は検定の過去問そのものではなく、同じレベル感で作成したオリジナルの練習問題です。

筆順モードの画のデータは、オープンソースの [KanjiVG](https://kanjivg.tagaini.net/) プロジェクトの筆順データ（[Creative Commons Attribution-Share Alike 3.0](https://creativecommons.org/licenses/by-sa/3.0/) ライセンス）から、このアプリで使う漢字ぶんだけを抽出して同梱しています（`stroke-data.js`）。

## ローカルでの実行

ビルド不要です。ファイルをそのまま開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## ファイル構成

- `index.html` — 画面構造（ホーム／クイズ／結果の3画面）
- `style.css` — スタイル
- `data.js` — 出題データ
  - `KANJI_DATA` / `CHOICE_DATA` / `PAIR_DATA` … 8級（3年生）用
  - `GRADE2_DATA` / `GRADE2_CHOICE_DATA` / `GRADE2_PAIR_DATA` … 9級（2年生）用
  - `RADICAL_GROUPS` … 部首なかまさがし用（級共通）
- `stroke-data.js` — 筆順モード用の画データ（KanjiVG由来、`STROKE_ORDER_DATA`）
- `app.js` — 出題ロジック・採点・成績保存（localStorage）

## データを増やす

`data.js` の各配列に以下の形式でオブジェクトを追加すると、自動的に出題されます。9級用データも同じ形式です。

読み方・書き取り・画数の3種類は `KANJI_DATA`（8級）/ `GRADE2_DATA`（9級）に追加:
```js
{ kanji: "医", word: "医者", reading: "いしゃ", strokes: 7 }
```

漢字えらび（二択）は `CHOICE_DATA` / `GRADE2_CHOICE_DATA` に追加:
```js
{ reading: "ようじん", correct: "用心", wrong: "用思" }
```

ことばのペアは `PAIR_DATA` / `GRADE2_PAIR_DATA` に追加（a・bどちらの向きからも出題される）:
```js
{ a: { kanji: "夜", reading: "よる" }, b: { kanji: "朝", reading: "あさ" } }
```

部首なかまは `RADICAL_GROUPS` に、同じ部首を持つ漢字を2字以上まとめて追加:
```js
{ radical: "氵（さんずい）", kanji: ["海", "活", "池"] }
```

筆順は `stroke-data.js` の `STROKE_ORDER_DATA` に、漢字1字をキーとして筆順どおりのSVGパス（`d`属性の文字列）の配列を追加する。`KANJI_DATA`・`GRADE2_DATA` に追加した漢字にここでも対応するエントリがあれば、自動的に筆順モードでも出題される（無ければそのモードだけ対象外になる）。
