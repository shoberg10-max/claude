# 資料作成支援アプリ

会議メモ・議事録から次回会議に向けた資料の構成案を作成し、あらかじめ用意したコンサルスライドのデザインパターンから内容に合うものを自動選択して、PowerPoint（.pptx）として書き出すブラウザアプリです。

ビルド不要の素の HTML / CSS / JavaScript で作られているので、`index.html` を開くだけで動きます（PowerPoint出力ライブラリの [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) はCDNではなく `js/vendor/` にローカル同梱しているため、社内の隔離ネットワーク環境でもそのまま動作します）。

## つかいかた

```
python3 -m http.server 8000
```

を実行して、ブラウザで `http://localhost:8000` を開いてください（`index.html` を直接ダブルクリックしても動作します）。

1. **Step 1（会議メモを入力）**: 会議メモ・議事録を貼り付けます。`#`/`##` の見出しや `-`/`・` の箇条書きがあると精度が上がりますが、フリーテキストでも解析します。「サンプルを試す」で動作イメージを確認できます。
2. **Step 2（構成案を確認・編集）**: メモから自動生成したスライド構成（見出し＋箇条書き）を確認し、自由に編集・追加・削除・並べ替えできます。
3. **Step 3（デザインパターンを自動選択 → PowerPoint書き出し）**: 各スライドの内容（項目数・キーワード・数値の有無など）から最もふさわしいデザインパターンを自動選択してプレビューします。プレビュー右上のプルダウンから手動で変更することも可能です。「PowerPointを書き出す」でPCに `.pptx` ファイルがダウンロードされます。

## 用意されているデザインパターン（9種類）

`js/patterns.js` で定義しています。

| パターン | 使いどころ |
|---|---|
| タイトル＋メッセージ | キーメッセージ＋補足の箇条書き。汎用のフォールバック |
| ボックス比較 | 2〜4個の選択肢・案を横並びで比較 |
| 2軸マトリクス | 4象限で分類・整理する |
| プロセス／フロー | 手順・ステップを順番に示す |
| ピラミッド構造 | 結論を頂点に、根拠（課題・原因・対策など）を土台に示す |
| Before／After | 現状と施策後を対比させる |
| タイムライン／ロードマップ | 日付・フェーズを時系列に並べる |
| 比較表 | 5項目以上を表形式で一覧比較 |
| KPIサマリー | 数値・指標をカードで並べる |

## デザインパターンを増やす（拡張方法）

パターンの追加・変更は `js/patterns.js` の1ファイルで完結します。以下の形のオブジェクトを `DocAssist.patterns` 配列に追加するだけで、自動選択・手動切り替えプルダウン・プレビュー・PowerPoint書き出しのすべてに反映されます。

```js
{
  id: 'kebab-case-id',        // 一意なID
  name: '表示名',
  description: '説明文（パターン一覧やプレビューに表示）',
  score(section) { ... },     // {heading, bullets} を見て 0〜10 程度で採点する関数
  renderBody(bullets) { ... },              // プレビュー用HTML文字列を返す（見出しは共通枠が描画）
  buildBody(pptxSlide, bullets, theme, box) { ... }, // PptxGenJSでスライド本文を組み立てる
}
```

`js/analyze.js` にキーワード検出・数値検出・箇条書きのキー：バリュー分解などの共通ヘルパーがあるので、新しいパターンの `score()` 実装に利用できます。色は `js/theme.js` の1箇所で管理しているので、配色を変えたい場合もそこを直すだけです。

## 社内LLM環境への接続ポイント

現在の実装は次の2箇所をルールベース（キーワード・件数などのヒューリスティック）で行っています。

- **構成案の生成**: `js/outline.js` の `DocAssist.outlineProvider(text)`
- **デザインパターンの自動選択**: `js/patternSelector.js` の `DocAssist.selectPattern(section)`

社内の隔離LLM環境に接続して精度を上げたい場合は、これらの関数を実際のLLM API呼び出しに差し替えてください。呼び出し側（`js/app.js`）はこの2つの関数を呼ぶだけなので、内部実装をルールベースからLLM呼び出しに置き換えても他のコードへの影響はありません。

## ファイル構成

```
index.html
css/style.css          全体のスタイル（プレビューのスライドデザインも含む）
js/app.js               画面遷移とUI（3ステップウィザード）
js/outline.js           会議メモ → 構成案（見出し＋箇条書き）のパーサー
js/analyze.js           キーワード検出・数値検出などの共通テキスト解析ヘルパー
js/patterns.js          デザインパターン定義（採点・プレビュー・PPTX生成）※拡張ポイント
js/patternSelector.js   構成案の各スライドに最適なパターンを選ぶロジック
js/pptxExport.js        構成案 → PowerPoint(.pptx) ファイルの書き出し
js/theme.js             プレビュー／PPTX共通の配色定義
js/vendor/pptxgen.bundle.js  PowerPoint生成ライブラリ PptxGenJS（MITライセンス、ローカル同梱）
```

## 制限事項

- 構成案生成・パターン選択は現状ルールベースのため、複雑な文章では見出し・箇条書きの区切りが意図通りにならないことがあります。Step 2で自由に修正してください。
- ブラウザ内で完結する設計のため、入力した会議メモやメモの内容が外部サーバーに送信されることはありません。
