# ゆるもじ島の漢字たんけん隊

漢検9級・8級の学習を「島を育てる冒険ゲーム」の中に埋め込んだ、小学1〜3年生向けブラウザゲームです。ビルド不要の素の HTML / CSS / JavaScript で作られているので、`index.html` を開くだけで動きます。

## あそびかた

```
python3 -m http.server 8000
```

を実行して、ブラウザで `http://localhost:8000` を開いてください（`index.html` を直接ダブルクリックしても動作します）。

## ゲームの流れ

1. **島MAP** — 漢字を覚えるほど島の霧が晴れ、森・村・城が出現します。
2. **今日の冒険（ミッション）** — 9級／8級／おまかせ（にがてな漢字優先）から選択。1回3字、各字につき「なぞり書き→よみ→かきとり（かんじ再認）→熟語のよみ」の4問、合計12問。
3. **リザルト** — 正解数に応じてXP・コインを獲得。レベルアップで「もじまる」が進化し、連続学習日数（ストリーク）も更新されます。
4. **たからばこ** — 5問正解ごとにチケットが貯まり、帽子・バッグ・ペットなどのコレクションアイテムをゲット。
5. **漢検チャレンジ** — 10字以上「おぼえた」ら挑戦可能。10問の模擬テストで 🟢合格圏 / 🟡あと少し / 🔴もう一度特訓 の3段階判定。
6. **かんじ図鑑** — 出会った漢字の音訓・意味・熟語・正解回数を確認できます。
7. **保護者のかたへ** — 週の学習日数、連続記録、9級/8級ごとの習得率、苦手な漢字、合格の目安を表示する保護者向けダッシュボード。

## 収録漢字（プロトタイプ版）

漢検9級相当・8級相当から、あそびやすい代表24字ずつ（計48字）を収録しています。本番投入時は9級160字・8級200字の全データに差し替え可能な構造です（`js/data.js` の `KANJI_DATA` 配列に追加するだけ）。

## 記録

レベル・コイン・連続学習日数・漢字ごとの習熟度・アイテムはブラウザの localStorage に保存されます（サーバーへの送信なし）。「さいしょから やりなおす」でリセットできます。

## ファイル構成

```
index.html
css/style.css
js/data.js      漢字データ・キャラクター・アイテム・島/たまごのステージ定義
js/storage.js   localStorage の読み書き
js/game.js      XP・コイン・習熟度・ストリーク・ガチャなどのゲームロジック
js/quiz.js      ミッション／漢検チャレンジの出題生成
js/app.js       画面遷移とUI描画
```
